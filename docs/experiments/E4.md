## Hypothesis

A lightweight binary classifier (frozen ImageNet-pretrained MobileNetV2
+ small head) can tell a plant leaf from a non-leaf image well enough
to reject human photos, animals, vehicles and buildings *before* the
disease model sees them — while letting ≥ 99% of real leaves through.

## Dataset

- **Leaf (positive):** PlantVillage training split, 60 images per class
  × 38 classes = 2,280 train; validation split, 20 per class × 38 =
  760 val. Total 3,040.
- **Non-leaf (negative):** Caltech 101, plant categories excluded
  (bonsai, joshua-tree, lotus, strawberry, sunflower, water-lilly);
  pool 8,830 images, balanced to 2,280 train / 760 val.
- **Totals:** 4,560 train, 1,520 validation. Seed 42.
- **Preprocessing:** 128×128, MobileNetV2 `preprocess_input` (0–255 →
  [-1, 1]). Note: this differs from the disease model's /255
  normalisation — the two must not be mixed up.

## Configuration

- Base: MobileNetV2, ImageNet weights, `include_top=False`, **frozen**.
- Head: GlobalAveragePooling2D → Dense(128, relu) → Dropout(0.3) →
  Dense(1, sigmoid), output = P(non-leaf); leaf probability = 1 − output.
- Optimiser Adam lr 1e-3, loss binary cross-entropy, 5 epochs, batch 32.
- Hardware: **Colab CPU** (no GPU; free GPU quota was exhausted).
  Training took ~391 s for 5 epochs.
- Parameters: 2,422,081 total (164,097 trainable).

## Results (validation, n = 1,520)

| Metric | Threshold 0.5 | Chosen threshold 0.8615 |
|---|---|---|
| Accuracy | 0.9980 | 0.9980 |
| Precision (leaf) | 0.9974 | 0.9987 |
| Recall (leaf) | 0.9987 | 0.9974 |
| F1 (leaf) | 0.9980 | 0.9980 |
| Non-leaf rejection | 0.9974 | 0.9987 |

- **ROC AUC: 0.9999.**
- Confusion at 0.5 (rows true [non-leaf, leaf], cols predicted
  [non-leaf, leaf]): [[758, 2], [1, 759]].
- Confusion at 0.8615: [[759, 1], [2, 758]].
- Epoch val accuracy: 0.9961, 0.9921, 0.9974, 0.9974, 0.9980.
  Final train accuracy 1.0000 (loss 0.0002).
- **Threshold rule:** the *highest* threshold that still keeps leaf
  recall ≥ 99% — the strictest gate that still lets real leaves
  through. That is 0.8615. (An earlier draft of the notebook comment
  said "lowest"; the code always picked the highest — comment fixed.)

## Before/after comparison (vs E1 baseline)

| Behaviour | Before (E1) | After (E4) |

| Human photo uploaded | Diagnosed as Tomato Late Blight 41.1% | Gate rejects with "does not look like a plant leaf"; no diagnosis shown (to be confirmed live) |

## Limitations

1. **No human faces in training or validation.** Caltech 101 has no
   people/faces category, so the 99.87% non-leaf rejection was measured
   on objects, animals, vehicles and buildings — *not* on faces. The
   live face-photo test is the true check for the original failure
   mode. If a face slips through, the next step is to add face photos
   to the negative class and retrain.
2. **Train accuracy 1.0000** suggests the head fits the training data
   completely; validation (99.80%) is the honest number, and the gap
   to real-world photos (field backgrounds, screenshots) is unmeasured.
3. Caltech images are clean object photos; screenshots, UI captures
   and heavily compressed images are a different distribution.
4. The gate adds a second ~12 MB model download on the app's first run.

## Incident during the run

The first `Run all` stopped at cell 5: the Caltech 101 zip contains
`caltech-101/101_ObjectCategories.tar.gz` (subfolder + `.gz`), while
cell 4 expected a plain `101_ObjectCategories.tar` in the working
directory, so `CALTECH_OK` was False and the CIFAR-10 fallback never
downloaded. Fixed without editing notebook code: extracted the
`.tar.gz` from the Colab terminal, re-ran cells 5–10. The notebook
has since been corrected (find-based extraction) so a fresh run works.

## Conclusions

- The gate works on its validation distribution: 99.80% accuracy,
  AUC 0.9999, and it keeps leaf recall above 99% while rejecting
  99.87% of non-leaf images at the chosen threshold.
- It is shippable: 11.6 MB, CPU-friendly, hosted on Drive like the
  disease model.
- The open question is face photos (limitation 1) — to be settled by
  the live test, not by the validation numbers.
